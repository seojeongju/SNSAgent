# SNSAgent 기능 설명서

> 버전: 문서 기준일 2026-08-04  
> 대상: SNSAgent 멀티에이전트 소셜 미디어 자동화 시스템

---

## 1. 제품 개요

**SNSAgent**는 자연어로 요청하면 LLM이 의도를 파악하고, 플랫폼별 서브에이전트(수집·분석·생성·게시)를 조합해 작업을 수행하는 멀티에이전트 시스템입니다.

핵심 특징은 다음과 같습니다.

- **의도 → 워크플로 자동 생성**: 사용자가 기능을 직접 고르지 않아도, 레지스트리(`agents_registry.json`)에 등록된 함수로 실행 계획을 만듭니다.
- **플랫폼 모듈화**: X(Twitter), TikTok, Instagram, YouTube 등을 crawler / analysis / interactive 단위로 분리합니다.
- **한국어 숏폼 생성**: Instagram Reels·YouTube Shorts용 대본·캡션을 한국어로 생성할 수 있습니다.
- **MCP 스타일 오케스트레이션**: Perception → Reasoning → Action → Memory 파이프라인으로 요청을 처리합니다.

---

## 2. 실행 방법

| 방식 | 명령 | 설명 |
|------|------|------|
| Streamlit UI | `streamlit run run_agent_app.py` | 웹 UI (`http://localhost:8501`). API 키 입력·채팅형 사용 |
| CLI | `python run_agent_cli.py.py` | 터미널 대화형 실행 |
| REST API | `python run_agent_api.py` | FastAPI (`http://0.0.0.0:8000`) |

사전 준비:

1. `pip install -r requirements.txt`
2. `.env`에 API 키 설정 (하단 [8. 환경 변수](#8-환경-변수--api-키) 참고)
3. (선택) `agents_registry.json`에 커스텀 에이전트 등록

## 3. 동작 구조

```
사용자 입력
    │
    ▼
Perception   입력 검증 · 보안 검사 · 요청 명확화(한국어 유지) · 결과 포맷
    │
    ▼
Memory       사용자별 채팅 이력 조회/저장 (현재 인메모리)
    │
    ▼
Reasoning    ChatGPT + agents_registry → 워크플로(steps) 생성
    │
    ▼
Action       agents.{플랫폼}.{카테고리} 모듈에서 function_id 동적 실행
    │
    ▼
Perception   결과를 사용자용 Markdown/JSON으로 정리 후 응답
```

| 모듈 | 경로 | 역할 |
|------|------|------|
| Perception | `core/perception/` | 입력 검증, 의도 재작성, 출력 문장 생성 |
| Reasoning | `core/reasoning/` | 에이전트 선택·워크플로 JSON 설계 |
| Action | `core/action/` | 스텝별 함수 호출·파라미터 전달 |
| Memory | `core/memory/` | 대화 이력 관리 |
| Prompts | `common/ais/prompts.py` | LLM 시스템 프롬프트(한국어 숏폼 포함) |
| Registry | `agents_registry.json` | LLM이 호출 가능한 기능 카탈로그 |

## 4. 기능 분류

### 4.1 오케스트레이션 (공통)

| 기능 | 설명 |
|------|------|
| 자연어 요청 처리 | 한국어/영문 요청을 실행 가능한 태스크로 재작성 |
| 워크플로 자동 설계 | 필요 에이전트·함수·순서를 LLM이 구성 |
| 다단계 실행 | 수집 → 정제 → 생성/게시 등 체인 실행 |
| 누락 파라미터 안내 | 첫 스텝에 필수 값이 없으면 사용자에게 요청 |
| 보안 필터 | SQL/프롬프트 인젝션·부적절 요청 차단 |
| 비용 표시(UI) | Streamlit에서 OpenAI 호출 비용 요약 표시 |

### 4.2 데이터 수집 (Crawler)

TikHub 등 외부 API를 통해 SNS 공개/연동 데이터를 조회합니다.

**대표 용도**

- 키워드·해시태그·유저 기반 콘텐츠 검색
- 프로필·팔로워·게시물·댓글·좋아요 수집
- 릴스/숏폼·라이브·샵(TikTok) 정보 조회
- 경쟁 계정·유사 계정 탐색

### 4.3 데이터 분석·정제 (Analysis)

| 기능 | 설명 |
|------|------|
| `clean_raw_data` | 수집 원본에서 다음 작업에 필요한 필드만 추출·정리 |
| 릴스/쇼츠 콘텐츠 생성 | 한국어 대본·캡션·해시태그 JSON 생성 (아래 4.5) |

크롤러 직후에는 보통 `clean_raw_data` 스텝이 이어지도록 Reasoning 프롬프트에 규칙이 있습니다.

### 4.4 플랫폼 액션 (Interactive)

계정 인증 후 게시·상호작용을 수행합니다.  
**현재 워크플로에 정식 등록·연결이 가장 완성된 플랫폼은 X(Twitter)** 입니다.

| 기능 유형 | 예시 |
|-----------|------|
| 게시 | 텍스트/미디어 포스트 |
| 소통 | 답글, DM |
| 관계 | 팔로우, 좋아요, 리트윗 |
| 관리 | 게시물 삭제 |

Instagram·TikTok·YouTube에도 업로드/댓글 등 코드가 있으나, 레지스트리 미등록 또는 클래스 형태로 남아 **자동 워크플로 호출이 제한**됩니다.

## 4.5 한국어 숏폼 콘텐츠 생성 (핵심 플랫폼)

SNSAgent 콘텐츠 생성의 주력 플랫폼은 다음 4가지입니다.

| 플랫폼 | 대본 | 캡션 | Python 함수 | Pages API |
|--------|------|------|-------------|-----------|
| Instagram Reels | ● | ● | `generate_reels_*` | `/api/generate` |
| YouTube Shorts | ● | ● | `generate_shorts_*` | `/api/generate` |
| TikTok | ● | ● | `generate_tiktok_*` | `/api/generate` |
| Facebook | ● | ● | `generate_facebook_*` | `/api/generate` |

`platform=all` 이면 4개 플랫폼 대본+캡션을 한 번에 생성합니다.  
Pages에서 호출 시 **OPENAI_API_KEY** Secret이 필요합니다.

## 8. 환경 변수 / API 키

| 키 | 필수 여부 | 용도 |
|----|-----------|------|
| `OPENAI_API_KEY` | **필수** | 요청 명확화, 워크플로 설계, 콘텐츠 생성, 데이터 정제 |
| `TIKHUB_API_KEY` | 수집 시 필수 | TikTok/Instagram/X 등 데이터 크롤링 |
| `X_API_KEY` / `X_API_SECRET` | X 액션 시 | X interactive |
| `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET` | X 액션 시 | X OAuth 토큰 |
| `YOUTUBE_API_KEY` | YouTube 연동 시 | YouTube API |
| `YOUTUBE_CLIENT_ID` / `YOUTUBE_CLIENT_SECRET` | 업로드 시 | YouTube OAuth |
| `ANTHROPIC_API_KEY` | 선택 | UI Claude 슬롯 (코어 주경로는 OpenAI) |
| `PANDAS_AI_API_KEY` | 선택 | analysis의 PandasAI 정제 |
| `AGENT_REGISTRY_PATH` | 선택 | 레지스트리 경로 (기본 `agents_registry.json`) |

최소 구성:

- **대본/캡션 생성만**: `OPENAI_API_KEY`
- **데이터 수집 포함**: `OPENAI_API_KEY` + `TIKHUB_API_KEY`
- **X 게시 포함**: 위 + X API/토큰 4종

## 9. 현재 한계 및 주의사항

1. **Memory는 인메모리**  
   DB 설정(`DB_*`)은 있으나 대화 이력은 프로세스 재시작 시 사라질 수 있습니다.

2. **일부 interactive/crawler 미연결**  
   Instagram·TikTok 업로드, YouTube 업로드·수집은 코드가 있어도 레지스트리에 없어 자동 워크플로에서 선택되지 않을 수 있습니다.

3. **FastAPI 진입점**  
   UI/CLI 대비 일부 API 시그니처·Memory 연동이 덜 맞춰져 있을 수 있습니다. 일반 사용은 Streamlit/CLI 권장.

4. **README 비전 기능**  
   WhatsApp/Quora 자동화, 백그라운드 다국어 DM 상시 응답 등은 로드맵성 설명이며 현재 레지스트리 기준으로는 미구현입니다.

5. **보안**  
   일부 interactive 샘플에 하드코딩된 자격 증명 흔적이 있을 수 있으므로, 운영 전 `.env`/시크릿 관리로 교체해야 합니다.

## 10. 디렉터리 안내 (기능 관점)

```
SNSAgent/
├── run_agent_app.py          # Streamlit UI
├── run_agent_cli.py.py       # CLI
├── run_agent_api.py          # FastAPI
├── config.py                 # 설정·API 키
├── agents_registry.json      # 호출 가능 기능 카탈로그
├── agents/                   # 플랫폼별 구현 (crawler/analysis/interactive)
├── core/                     # Perception / Reasoning / Action / Memory
├── common/ais/prompts.py     # 한국어 숏폼·오케스트레이션 프롬프트
└── images/                   # SNSAgent 로고·플로우 이미지
```

새 기능을 추가할 때:

1. `agents/{platform}/`에 함수 구현  
2. `agents_registry.json`에 `agent_id` / `function_id` / 파라미터 등록  
3. (필요 시) `common/ais/prompts.py`에 생성 규칙 보강  

등록만 하면 Reasoning이 워크플로에 자동으로 포함시킬 수 있습니다.

## 11. 요약

SNSAgent는 **자연어 기반 SNS 운영 에이전트**로, 현재 실무에서 바로 쓰기 좋은 축은 다음과 같습니다.

1. **Instagram Reels / YouTube Shorts 한국어 대본·캡션 생성**  
2. **TikTok·Instagram·X 데이터 수집·정제**  
3. **X 계정 게시·상호작용**  
4. **LLM 오케스트레이션으로 위 기능을 하나의 대화 흐름에 연결**

포스팅 자동화(IG/TikTok/YouTube 업로드)와 추가 플랫폼은 코드 기반이 있으나, 레지스트리·인증 연결을 마무리하면 확장할 수 있는 구조입니다.
